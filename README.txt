DETALLE DE CUMPLEAÑOS PARA CAMILA

Cómo abrirlo:
1. Descomprime la carpeta.
2. Abre el archivo index.html con Chrome, Edge, Firefox o Safari.
3. No requiere internet ni instalación.

Incluye:
- Recorrido interactivo de cumpleaños.
- Mensaje personalizado.
- Galería con fotografías.
- Diseño adaptable a celular y computador.
- Animaciones, velitas y confeti final.

Consejo: en celular, envía toda la carpeta comprimida o publícala en un hosting estático para compartirla mediante enlace.
